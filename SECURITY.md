## Reporting a Vulnerability

If you discover a security vulnerability within the **esp-fusion-sense** platform, please report it responsibly rather than disclosing it publicly.

* **Where to Report:** Send details regarding the vulnerability privately via repository maintainer contact channels or a security advisory notice.
* **Update Expectations:** You can expect an initial acknowledgment of your report within **48 hours**, along with a timeline for further investigation and remediation updates.
* **Resolution Process:** If accepted, a patch will be prepared, tested through our continuous integration pipeline, and disclosed alongside an updated release advisory.
